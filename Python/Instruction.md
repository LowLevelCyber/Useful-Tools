This script iterates through a user provided list separated by a new line of MITRE Technique URLs.

Ensure your list is in .txt format, and provide the full path after `with open`.

This should be the only modification to make, and the tables pulled should include the following:
**Procedural Examples**
This will pull: ID, Name, and Description.

**Mitigations**
This will pull: ID, Mitigation, and Description.

**Detection**
This will pull: ID, Data Source, Data Component, Detects.
